# Game Vision

## One-line concept

"위험을 죽일지, 지울지, 직접 피할지를 같은 자원 안에서 판단하는 웹 핵앤슬래시."

## Required conditions

1. 하나의 공격에도 처치·무효화·회피라는 서로 다른 해법이 있을 것
2. 회피와 무효화가 공유 방어 자원을 두고 경쟁할 것
3. 높은 피해와 높은 넉백이 서로 다른 위험을 해결할 것
4. 데스크톱 화면에서 공격 범위와 타이밍을 한눈에 읽을 수 있을 것
5. 잘한 대응이 궁극기라는 강한 전장 정리 보상으로 이어질 것
6. 60~90초 안에 전투 규칙의 재미를 판단할 수 있을 것

## Initial success criteria

- 적의 공격을 봤을 때 단순 회피보다 다른 해법을 먼저 검토하게 된다.
- 집중 베기와 충전 베기의 선택 이유가 즉시 이해된다.
- 회피와 무효화를 모두 쓰며, 둘 중 하나를 무작정 남발하지 않는다.
- 인터럽트·투사체 제거·완벽 회피가 궁극기 충전으로 명확히 보상된다.
- 90초 종료 뒤 결과 로그로 실제 선택 분포를 확인할 수 있다.
